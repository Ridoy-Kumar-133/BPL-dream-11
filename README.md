# 🏏 Cricket Player Selection App

A simple and responsive **Cricket Player Selection** web application built with **React and TypeScript**. Users can browse available cricket players, view player information, and select their favorite players.

Built with **Tailwind CSS** and **DaisyUI** for a clean and responsive user interface.

## 📖 Project Overview

The **Cricket Player Selection App** allows users to explore a list of cricket players loaded dynamically from a local `Data.json` file.

Users can:

- Browse available cricket players
- View player information
- See country/origin
- Check player type
- View batting and bowling styles
- See player prices
- Select players
- Switch between available and selected players

The project was built to practice **React, TypeScript, component-based development, state management, and responsive UI design**.

## ✨ Key Features

### 🏏 Player Card Display

Each player is displayed in a clean card containing:

- Player name
- Country / origin
- Player type
- Batting style
- Bowling style
- Player price
- Player image

### 🔄 Available & Selected Players

Users can easily switch between:

- **Available Players**
- **Selected Players**

This makes it easy to manage the selected cricket team.

### ⚡ Dynamic Data Loading

Player information is loaded dynamically from a local `Data.json` file.

### 📱 Responsive Design

The application is fully responsive and works across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

### 🎨 Modern UI

The project uses **Tailwind CSS + DaisyUI** to create a clean and user-friendly interface.
